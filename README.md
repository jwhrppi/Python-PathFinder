## ✦ ABOUT THE GAME

### **Python Pathfinder** is an educational puzzle game designed to introduce foundational Python programming concepts in an engaging way.

Players guide **Dino** through various maze levels to collect his lost coins by solving pathfinding logic and writing simple Python commands!

---

## ✦ BACKGROUND & ORIGIN

### 🎓 **Matriculation Project**
This project was originally developed during my **Matriculation studies** for the **Digital Creative Competition** under the *Computer Programming* subject. 

### 🎯 **Objective**
To combine interactive gameplay with beginner-friendly computer science principles, making learning Python logic fun and accessible for students.

---

## ✦ KEY FEATURES

* **Meet Dino:** Guide Dino safely through paths while collecting coins.
* **Learn Basic Python:** Apply simple algorithms and code-based logic to solve pathfinding puzzles.
* **Playable in Browser:** Fully hosted and playable directly on web browsers via Itch.io.
